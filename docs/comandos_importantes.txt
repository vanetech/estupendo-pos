Al encender el PC para volver a trabajar en el proyecto:

1) Abrir Visual Studio Code. Entrar a la carpeta raíz del proyecto C:\Users\PERSONAL\Documents\proyectos\estupendo-pos
2) Verificar que Docker desktop esté corriendo (running).
3) Levantar los contenedores:
	>>	docker compose up -d
4) Entrar al contenedor de Laravel:
	>>	docker compose exec app bash
	Ir a la carpeta laravel:
	>>	cd laravel
5) Verificar que artisan esté listo:
	>> php artisan
6) Para poner a correr el proyecto, usar el comando:
	>>	php artisan serve --host=0.0.0.0 --port=8000
